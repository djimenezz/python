# python
Repositorio para ejercicios con python

## Scripts

- `group_by_date.py`: lee una hoja de Excel y agrupa las filas por fecha. Se puede ejecutar desde la consola:

```bash
python group_by_date.py <ruta_excel> <nombre_hoja> [--date-column FECHA]
```

El parámetro `--date-column` permite especificar el nombre de la columna que contiene la fecha.
